# Message Queues Module

This module contains the Task 1 and Task 2 description for the message queues home task.

The working implementation was moved into the async API solution under `04_asynchronous_apis/sources/TicketingSystem.AsyncApi` so the notification flow uses RabbitMQ, a notification status table, and a real email-provider integration path.

If you want to run the solution, use the async API project and the instructions in its README.
